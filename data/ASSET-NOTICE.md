# Lineup avatar derivatives

`avatar-parts.json` contains a small curated, normalized derivative subset of the Product.ai-supplied Shutterstock artwork licensed for Lineup. Use only within Lineup. Do not redistribute as a standalone asset library. Original EPS files, the confidential handoff and the experimental builder are not part of this repository or deployment.

Event artwork in `event-artwork.json` is a manual review manifest. Its initial image is existing generic LA Tech Week sample artwork, explicitly labeled as not organizer artwork. Unmapped events use a title-based placeholder. Replace entries only with approved organizer-supplied posters; no scraping or ingestion pipeline is included.
